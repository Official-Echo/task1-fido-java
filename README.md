# Реалізація завдання на Java

Виконання Завдання 1 для FIdo: знайти вузол на позиції ⌊2n/3⌋ - 1 в однозв'язному списку.

Основна частина це бібліотека з класами `Node<T>` і `TwoThirdsOfLinkedList` у пакеті `fido.task1`. До неї додатково створена консольна програма `fido.task1.Main`.

## Вхідні дані

Якщо не подано нічого, вхід буде прочитано з консолі.

Якщо подано одне число n, буде зроблено список довжиною n зі значеннями 0..n-1.

Якщо подано список значень `"a -> b -> c -> d"` (будь-що з розділювачем `->`), буде використано саме його. Список треба брати в лапки, бо інакше `>` сприйметься оболонкою як перенаправлення.

## Запуск

Потрібна Java 25.

### Спосіб 1: готовий jar

1. Завантажити `node-task-1.0.0.jar` з Releases.
2. Запустити `java -jar node-task-1.0.0.jar 5`.

### Спосіб 2: збірка через Maven

1. Завантажити весь репозиторій (потрібні JDK 25 і Maven).
2. У кореневій теці виконати `mvn clean package`.
3. Jar буде в `target/node-task-1.0.0.jar`, запускається так само.

## Бібліотека

```java
Node<Integer> head = new Node<>(0, new Node<>(1, new Node<>(2, new Node<>(3, new Node<>(4)))));
Node<Integer> result = TwoThirdsOfLinkedList.getTwoThirdsNode(head);
System.out.println(result == null ? "null" : result.data); // 2
```

Jar не має залежностей, його достатньо додати в classpath.

## Опис

Пошук іде за один прохід, O(n) за часом і O(1) за пам'яттю. Вказівник `res` стартує з голови, `curr` біжить списком до кінця. На кожному кроці `len` росте на 1, якщо `len mod 3 ≠ 1`, `res` теж переходить на наступний вузол. Для списку коротшого за 2 елементи повертається `null`.

Тести запускаються командою `mvn test`.
